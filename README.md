# 📚 BookScope

A full-stack book analytics platform that scrapes data, provides APIs, and visualizes insights with an interactive UI.

---

## 🚀 Features

- 🔍 Search books (with debounce optimization)
- ⭐ Filter by rating & category
- 🔽 Sort by price & rating
- 📊 Data visualization (Bar & Pie charts)
- 📄 Pagination (efficient data loading)
- ❤️ Favorites system (with localStorage)
- 🤖 Smart recommendations
- ⚖️ Book comparison tool
- 🧬 Book DNA (visual data representation)
- 🎭 Grid/List view toggle

---

## 🛠️ Tech Stack

### Backend
- Python
- Flask
- BeautifulSoup (Web Scraping)

### Frontend
- React.js
- Recharts (Data Visualization)

## 🧠 Unique Features

### 🧬 Book DNA
Each book has a visual identity:
- Color → Rating
- Width → Price

### 🎯 Smart Filtering
Users can filter and explore books dynamically.

### ⚡ Debounced Search
Improves performance by reducing unnecessary filtering calls.
